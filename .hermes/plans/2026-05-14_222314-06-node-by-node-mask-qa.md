# 06 Outfit Workflow: Node-by-node mask QA plan

## Goal

Stop treating the 06 outfit workflow as one integrated black box. The current v4e22 image output improved, but the masks themselves are structurally suspicious. Rebuild confidence by isolating each mask node, making each one visually correct first, then recombining into the canonical workflow.

Strict mask diagnosis:

1. `protecthands` is not actually a clean hand mask.
   - It is blocky and includes too much wrist/cuff/sleeve material.
   - It misses or simplifies finger shape.
   - It is generated from Florence hand/both-hands/fingers plus grow/blur, then postprocessed by node `60`.
   - Risk: node `30` composites old outfit cuff/sleeve back over the new outfit.

2. `hand_added` is too geometric/blocky.
   - The fallback shape is not anatomy-aware enough.
   - It fixes missing-hand coverage, but it is not good enough as a final preservation mask.
   - Risk: rectangular hand/cuff islands become hard seams.

3. `edit_nohands` is downstream weirdness, not the first cause.
   - It looks strange because it subtracts the bad hand protection mask from the full edit mask.
   - If `protecthands` is wrong, `edit_nohands` will necessarily have wrong holes around cuffs/hands.
   - Problem node chain: `47/48/58 -> 59 -> 50 -> 51 -> 60 -> 52 -> 53`.

4. `fg_mask` is a separate foreground cleanup mask, not the first hand/cuff cause.
   - It still has side/edge artifacts and should be checked independently.
   - It should not be used to hide bad hand protection.

## Proposed approach

Use isolated node QA, not full workflow iteration.

Each stage should produce:

- raw mask PNG
- mask over source image
- mask boundary overlay
- crop contact sheet for t5 and pink01
- pass/fail notes

Only after a stage passes on multiple characters should it be connected to the next stage.

## Stage plan

### Stage A: Ground truth inputs

Files/nodes:

- source image node `3`
- character alpha node `4`
- face/hair/neck protection nodes `7-14`
- hand detector nodes `47`, `48`, `58`

Validation:

- Character alpha covers full character, not grey background.
- Face/hair/neck protection does not include torso/collar incorrectly.
- Florence hand masks are inspected before grow/blur.

Expected output:

- If Florence masks already include cuffs, do not pass them directly into preservation.

### Stage B: Raw Florence hand mask QA

Nodes:

- `47` hand
- `48` both hands
- `58` fingers
- `59` union

Validation:

- Masks must be saved separately before `GrowMask`.
- Check whether `hand`, `both hands`, and `fingers` each include sleeve/cuff.
- Decide which source is reliable enough to keep.

Likely fix:

- Do not union all Florence hand masks blindly.
- Use Florence masks only as spatial priors.
- Apply source-image skin filter before grow/blur.

### Stage C: Hand fallback node as isolated unit

Node:

- `60` `VN_AutoHandFallbackProtectionMask`

Current problem:

- Output is too blocky and includes old cuff/sleeve regions.

Proposed rewrite direction:

- Split node outputs:
  1. `existing_hand_refined`
  2. `skin_candidate`
  3. `wrist_bridge_candidate`
  4. `cuff_trimmed_final`
  5. debug overlay
- Do not merge these internally until each debug output looks correct.
- Add component filtering by shape and vertical position.
- Preserve skin/fingers, not old cuffs.

Pass criteria:

- White mask covers palms/fingers and minimal wrist skin.
- White mask does not cover cardigan cuff ribbing or old sleeve fabric.
- Works on t5 and pink01.

### Stage D: Edit mask after hand subtraction

Nodes:

- `52` face/hair/hand protection union
- `53` edit mask minus protection

Validation:

- `edit_nohands` should have clean hand-shaped holes only.
- No rectangular holes around cuffs.
- No huge accidental holes in torso/sleeves.
- Hands should be protected; old cuffs should remain editable.

Pass criteria:

- New outfit can regenerate cuff/sleeve area.
- Original hand is preserved.
- There is no old-cuff island left unedited.

### Stage E: Composite route QA

Node:

- `30` `ImageCompositeMasked`

Validation:

- Composite source should paste only face/hair/hands, not old cuffs.
- Compare raw inpaint vs fullfit with a difference/overlay sheet.

Pass criteria:

- Hands look like source hands.
- Cuffs belong to the generated target outfit.
- No beige cardigan cuff from source appears in final.

### Stage F: Foreground cleanup independently

Node:

- `81` `VN_OutfitForegroundResidueCut`

Validation:

- Input: already-correct fullfit.
- It should only remove background-connected neck/side grey residue.
- It must not be responsible for hand/cuff fixes.

Pass criteria:

- Dark/gray/light background composites show no neck/sleeve ghost.
- No hand/finger/outfit overcut.

## Decision

The user's suggestion is correct: node-by-node isolation is the safer path. The current integrated workflow can produce acceptable-looking outputs while still carrying bad masks. Those bad masks will fail on future characters/outfits. Do not continue tuning the final result only; first make the individual masks clean and character-agnostic, then merge.
