# 게임 스케일 문서

상태: DRAFT

## 1차 목표

PC용 Ren'Py 10~15분 이세계 학원 판타지 착각물 vertical slice.

완성 목표는 “긴 게임”이 아니라 다음을 한 번에 검증하는 것입니다.

1. 착각물 구조가 재미있게 작동한다.
2. 이세계 마법 학원 배경이 첫 장면에서 이해된다.
3. 메인 히로인 하린이 “학생회 감찰 담당/의심자”로 매력 있게 보인다.
4. 선택지가 실제 의도와 주변 해석의 차이를 만든다.
5. 시작부터 데모 엔딩까지 QA 가능하다.

## 콘텐츠 범위

| 항목 | 1차 데모 범위 | 후순위 |
|---|---:|---|
| 플레이 시간 | 10~15분 | 30분+ 확장 |
| 루트 | 메인 히로인/감시자 하린 중심 1루트 | 다중 히로인/파벌 루트 |
| 엔딩 | 2~3개: 대현자 소문 / 하린 의심 / 균형 후크 | 배드/히든/진실 루트 |
| 배경 | 소환 강당, 마법 실습실 1~2장 | 기숙사/도서관/결투장/학생회실 |
| 캐릭터 스프라이트 | 하린 3~5표정 | 라이벌/교수/학생회 캐릭터 |
| CG | 측정구, 봉인 마도구 1~2장 | 결투/고대 유적/파벌 이벤트 CG |
| 음성 | 일단 보류 또는 하린 주요 라인만 | 풀보이스 |
| BGM/SFX | 마법진, 웅성거림, 마도구 정지음 | 캐릭터 테마/전투 음악 |
| UI 커스텀 | 기본 UI 정돈 + 한국어 가독성 | 완전 판타지풍 UI |
| 시스템 | 선택지 + 변수 기반 분기 | 평판 UI/조사 UI/마법 시스템 |

## 시나리오 분량 기준

- 장면 수: 5개
- 대사/내레이션 블록: 90~150개
- 선택지: 3~4개
- 저장 변수: 8~10개 이하
- 첫 구현은 텍스트 중심, 이후 에셋 교체

## 에셋 제작 우선순위

1. `bg_summoning_hall` — 왕립 마법 학원 강당/마법진
2. `bg_magic_lab` — 마법 실습실/고대 마도구
3. `harin_neutral`, `harin_suspicious`, `harin_surprised`, `harin_analytical`, `harin_soft_smile`
4. `cg_magic_measurement_orb` — 측정구 오류 CG
5. `cg_sealed_artifact` — 봉인 마도구 폭주/정지 CG
6. SFX: magic_pulse, students_murmur, artifact_shutdown

## 제외 범위

1차 데모에서 하지 않습니다.

- 모바일 UI 최적화
- 다중 히로인 루트
- 복잡한 마법 커스터마이징 시스템
- 파벌 정치 전체 구현
- 라이브 애니메이션/LivePortrait
- 풀보이스
- Steam/배포 패키징
- 주인공의 진짜 혈통/완전한 힘 확정. 단, 작은 숨은 재능 떡밥은 허용

## 성공 기준

- Ren'Py lint 통과
- 시작부터 데모 엔딩까지 도달 가능
- 한국어 폰트가 깨지지 않음
- 착각 코미디가 최소 3번 이상 명확히 작동함
- 선택지에 따라 `reputation`, `misunderstanding_score`, `harin_trust`, `harin_suspicion` 중 일부가 변화함
- 스프라이트/선택지/대사창이 서로 가리지 않음
- 주요 장면 3개 이상 스크린샷 QA 완료
- 사용자가 “이 방향으로 다음 장면을 만들어도 된다”고 판단 가능
