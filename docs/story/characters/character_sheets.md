# 캐릭터 설정 시트

상태: DRAFT

이 문서는 실제 스크립트/에셋 생성의 기준입니다. 승인 전까지는 임시 canon입니다.

---

## 1. 주인공

| 항목 | 내용 |
|---|---|
| 표시명 | 서진 |
| 변수 ID | `player_name`, 기본값 `서진` |
| 역할 | 이세계 전이자 / 왕립 마법 학원 편입생 / 착각의 중심 |
| 실제 능력 | 현대인 상식, 관찰력, 운. 마법 지식은 거의 없음. 단, 후반에 “마법식의 빈틈을 직감적으로 보는” 작은 숨은 재능이 드러날 여지 있음 |
| 주변 평판 | 측정 불능 마력의 소유자, 고대식 해석자, 숨은 대현자 후보 |
| 나이/학년 | 고등학생 또래 / 학원 편입 2학년 상당 |
| 첫인상 | 조용하고 말수가 적어 보임. 사실은 상황을 몰라서 말을 아끼는 중 |
| 핵심 욕망 | 튀지 않고 살아남기, 원래 세계로 돌아갈 단서 찾기 |
| 결핍 | 이세계 상식이 없어 말실수를 자주 함 |
| 장점 | 눈치가 빠름, 위험한 순간에 본능적으로 안전한 선택을 함, 운이 좋음 |
| 약점 | 자기 행동이 어떻게 해석되는지 늦게 알아차림 |
| 말투 | 속마음은 당황/회피형. 겉으로는 짧고 애매하게 말해 신비롭게 오해받음 |
| 플레이어 선택 축 | 회피 vs 애매한 허세, 솔직함 vs 침묵, 안전 선택 vs 우연한 대담함 |

### 착각물 기능

주인공의 실제 의도와 주변 해석이 항상 어긋납니다.

| 주인공의 실제 의도 | 주변 해석 |
|---|---|
| 몰라서 침묵함 | 모든 가능성을 계산 중 |
| 대충 고른 답 | 고대 마법의 핵심을 찌른 선택 |
| 위험해서 뒤로 물러남 | 상대에게 먼저 움직이라고 압박 |
| 실수로 마도구를 건드림 | 봉인식을 해제 |
| “그럴 수도 있겠네요”라고 얼버무림 | 귀족 파벌의 논리를 꿰뚫은 선언 |

## 2. 메인 히로인

| 항목 | 내용 |
|---|---|
| 이름 | 윤하린 |
| 변수 ID | `harin` / 신뢰도 `harin_trust` / 의심도 `harin_suspicion` |
| 역할 | 학생회 감찰 담당 / 작고 야무진 츤데레 감시자 / 주인공의 오해를 제일 먼저 잡아내는 사람 |
| 신분 | 왕립 마법 학원 학생회 소속 감찰 담당. 귀족 파벌과 거리를 두지만, 규칙과 기록에는 누구보다 엄격한 실력파 |
| 실제 성격 | 책임감이 강하고 똑똑하지만 감정이 얼굴에 먼저 드러난다. 차갑게 말하려 해도 귀 끝이 빨개지거나 말끝이 흔들리는 타입 |
| 첫인상 | 주인공의 “측정 불능” 판정을 보고 경계하지만, 동시에 너무 허술하게 당황하는 모습 때문에 페이스가 흔들린다 |
| 핵심 욕망 | 위험한 마법 사고를 막고, 작은 체구/어린 인상 때문에 얕보이지 않고 감찰 담당으로 인정받고 싶다 |
| 결핍 | 귀엽게 보이는 외모와 실제 능력 사이의 간극 때문에 “무섭게 굴어야 한다”는 강박이 있다 |
| 장점 | 마법 이론, 기록 분석, 빠른 관찰력, 책임감. 당황해도 해야 할 일은 한다 |
| 약점 | 칭찬과 솔직한 부탁에 약하다. 돌봐주고 나서도 “감찰일 뿐”이라고 우긴다 |
| 말투 | 정중한 존댓말 기반. 의심할 때는 똑 부러지지만, 당황하면 짧은 반박/헛기침/말끝 흐림이 나온다. 핵심 톤은 “바, 바보 같은 말 하지 마세요. 기록상 필요한 질문일 뿐입니다.” |
| 시각 키워드 | 작은 체구의 상반신 VN 스프라이트, 큰 눈, 둥근 얼굴, 살짝 삐친 입, 옅은 홍조, 짧은 밤색/체스트넛 보브 또는 낮은 양갈래, 밝은 베이지 가디건, 흰 블라우스, 네이비 리본타이, 네이비 주름치마, 단정하지만 귀여운 학생회 감찰 느낌 |
| 표정 세트 | neutral_pout, suspicious_blush, startled_tsundere, flustered_angry, tiny_soft_smile |

### 관계 변화

1. 첫 만남: 감시 + 페이스 흔들림. “수상합니다. 아주 수상한데… 왜 그렇게 아무것도 모르는 얼굴을 하시는 거죠?”
2. 중반: 검증 + 돌봄. “혼자 돌아다니지 마세요. 감찰 대상이 넘어지면 제 보고서가 늘어나니까요.”
3. 후반: 츤데레 협력. “믿는다는 뜻은 아닙니다. 단지… 당신이 또 사고 치면 제가 제일 먼저 뛰어가야 하니까요.”

### 착각 구조에서의 역할

- 다른 학생들이 주인공을 과하게 떠받들 때, 하린은 유일하게 의심한다.
- 단, 냉혈 감시자가 아니라 “수상해서 따라다니다가 자꾸 챙겨주는” 귀여운 츤데레 축이다.
- 주인공의 운 좋은 결과를 볼수록 의심과 걱정이 동시에 커진다.
- 데모 후반에는 감시자에서 “믿지는 않지만 내버려둘 수 없는 담당자”로 이동한다.

## 3. 라이벌/오해 증폭 캐릭터

| 항목 | 내용 |
|---|---|
| 이름 | 레온하르트 또는 강한 판타지명, 추후 결정 |
| 변수 ID | `rival_pressure` |
| 역할 | 귀족 파벌 대표 / 주인공의 행동을 정치적 선언으로 오해하는 인물 |
| 성격 | 자존심이 강하고 해석이 과함 |
| 기능 | 주인공의 평범한 말 한마디를 “결투 신청”이나 “파벌 견제”로 확대 |
| 1차 데모 등장 | 직접 등장 또는 소문/대사로만 암시 가능 |

## 4. 학원장/교수 후크 캐릭터

| 항목 | 내용 |
|---|---|
| 이름 | 엘리시아 교수 또는 학원장, 추후 결정 |
| 변수 ID | `faculty_interest` |
| 역할 | 주인공을 특별 관찰 대상으로 지정하는 어른 캐릭터 |
| 성격 | 온화하지만 속을 알 수 없음 |
| 기능 | 데모 마지막 후크: “그 학생, 내일 고대마도학 실습에 배정하세요.” |

## 5. 캐릭터 에셋 우선순위

1. 하린 neutral_pout/suspicious_blush 상반신 VN 스프라이트
2. 하린 startled_tsundere/flustered_angry/tiny_soft_smile 표정
3. 주인공은 1인칭 시점이므로 초반 스프라이트 불필요
4. 라이벌은 데모 1차에서는 실루엣/소문/이름만 가능
5. 교수/학원장은 마지막 후크용 목소리 없는 텍스트 등장 가능

## 6. 승인 전 금지

- 주인공을 1차 데모에서 완전한 먼치킨으로 확정하지 않기. 숨은 재능은 후반 떡밥으로만 남기기
- 하린을 처음부터 완전 호감형으로 만들지 않기. 귀여운 츤데레 반응은 허용하되, 공식 감찰/의심 축은 유지하기
- 라이벌/교수 이름을 script canon으로 고정하지 않기
- 음성 생성 시작하지 않기
- 최종 스프라이트로 semantic path 승격하지 않기
