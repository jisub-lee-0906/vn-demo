# 메인 루트 블루프린트

상태: DRAFT

## 루트 목표

주인공이 왕립 마법 학원에 전이/편입되고, 측정구 오류와 봉인 마도구 사고를 통해 “숨겨진 대현자”로 오해받기 시작하는 10~15분 데모 루트. 초반에는 운 좋은 평범한 사람처럼 보이되, 후반에는 작은 숨은 재능의 떡밥을 남긴다.

## 장면 카드 요약

| Scene ID | 목적 | 주인공 실제 의도 | 주변 해석 | 선택지 |
|---|---|---|---|---|
| `ch01_s01_summoning_hall` | 이세계 학원 도입 | 상황 파악 | 침착한 등장 | 첫 반응 |
| `ch01_s02_magic_measurement` | 측정 불능 사건 | 시키는 대로 손 올림 | 대마력 은폐 | 침묵/해명/재시도 |
| `ch01_s03_harin_interrogation` | 하린과 첫 대화 | 들키지 않게 얼버무림 | 진의를 숨김 | 솔직함/애매함 |
| `ch01_s04_artifact_accident` | 마도구 폭주 | 도망치려 함 | 봉인식 해석 | 물러남/멈춤/건드림 |
| `ch01_s05_special_observation` | 명성 후크 | 집에 가고 싶음 | 특별 관찰 대상 | 받아들임/부정 |

## 확정된 방향

- 주인공: 후반에 숨은 재능이 조금 드러나는 후자 방향.
- 하린: 학생회 감찰 담당인 전자 방향.
- 첫 사건: 측정구 오류 + 봉인 마도구 사고인 전자 방향.

## 엔딩 초안

### `ending_great_sage_rumor`

조건: `reputation >= 3` 또는 `misunderstanding_score >= 3`

학생들 사이에 “측정 불능 편입생이 고대 마도구를 해제했다”는 소문이 퍼진다. 주인공은 그냥 운이 좋았다고 생각하지만, 학원장은 특별 관찰을 명한다.

### `ending_harin_suspicion`

조건: `harin_suspicion >= 2` 또는 `reputation < 3`

하린은 주변의 과대평가를 그대로 믿지 않는다. 하지만 주인공이 사고를 막은 것은 사실이라, 직접 감시하겠다고 선언한다.

### `ending_balanced_hook`

조건: `harin_trust >= 1`, `reputation >= 2`, `harin_suspicion <= 1`

하린은 주인공이 수상하지만 악의는 없다고 판단한다. 다음 실습부터 주인공 옆에 서겠다고 말한다.

## 변수 흐름

- 착각이 커질수록 `misunderstanding_score` 증가.
- 공식 평판/소문은 `reputation` 증가.
- 하린이 “정말 모르는 사람 같다”고 느끼면 `harin_trust` 증가.
- 하린이 “연기일 수 있다”고 느끼면 `harin_suspicion` 증가.
